KatSAT Design System

Light mode only. Every value below is a CSS custom property defined in section 1 of public/styles.css — this page loads that same file, so it can never drift from the app.

Principles

  1. Hairlines, not shadows. Exactly one shadow token exists and it is reserved for dialogs. Everything else is separated by a 1px border.
  2. One accent. A single green carries brand, primary action, and selection. Color elsewhere means something specific: correct or wrong.
  3. Six type sizes. Adding a seventh is almost always solvable with weight or color instead.
  4. One primary button per view. If two things look equally important, neither reads as important.
  5. Space on a 4px grid. Use the tokens; arbitrary margins are what make a UI feel loose.

Color

Neutrals are very slightly warm so large white areas do not feel clinical. Change the three accent tokens and the whole product re-skins.
